# Data Systems Design Handbook

HLD and LLD concepts for data engineering and analytics, in simple terms

## How to use this handbook

This handbook explains how to design a data system, from the first questions to working pipelines. You don't need system design experience, and basic SQL is enough.

Each chapter follows the same pattern:

- **In one line:** the idea in a single sentence.
- **Think of it like:** an everyday comparison.
- **The picture:** a diagram showing how it works, with the technical words explained inside.
- **Remember:** the one thing to take away.

New to the topic? Read in order. Designing a system now? Start with the checklist in chapter 29.

Examples use a made-up online store, so the numbers are only illustrations. Tool names are common examples, not requirements.

## The series

The handbook is released in four parts. Each new part is announced on the [releases page](https://github.com/seeralikhith/Data_System_Design/releases), so you can watch the repository to hear when the next one is out.
